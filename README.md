## ✨ Features

- 🤖 **Multi-Agent AI System** — Chat, Coding, PDF, Image Analysis, PPT, Web Search
- 💬 **Real-time Chat** — ChatGPT-like interface with streaming
- 🎨 **Code Editor** — Monaco editor with syntax highlighting  
- 📄 **PDF Processing** — Upload and query PDFs with RAG
- 🖼️ **Vision Agent** — Analyze images using AI
- 📊 **PPT Generator** — Generate presentations with AI
- 🔍 **Web Search** — Tavily-powered real-time search
- 🔐 **Google Auth** — Firebase authentication
- 💳 **Billing System** — Razorpay integration with credit plans
- 🐳 **Docker Ready** — Microservices architecture

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React 19, Vite, Tailwind CSS v4, Redux Toolkit |
| Backend | Node.js, Express (microservices) |
| AI | LangChain, LangGraph agents |
| Database | MongoDB |
| Cache | Redis |
| Auth | Firebase (Google Sign-In) |
| Payments | Razorpay |
| Storage | AWS S3 |
| Deploy | Docker + GitHub Actions |
